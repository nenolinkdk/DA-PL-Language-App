| Marker | Meaning |
|---|---|
| V1 | required for first usable implementation |
| NICE-TO-HAVE | explicitly deferred |
| OPEN | decision still required |
| LINGUISTIC REVIEW | must be reviewed before content/design is frozen |

## Documentation maintenance

If code and documentation disagree, do not silently choose one. Determine whether the implementation or specification is current, update the losing side, and record significant product decisions in DECISIONS.md.
