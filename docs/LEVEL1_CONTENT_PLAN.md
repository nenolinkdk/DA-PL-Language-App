# Level 1 Production Plan

## Learner profile

Danish-speaking beginner with little Polish, preparing for practical use in Poland.

## Production sequence

| # | Lesson | Core outcome | FSM candidate |
|---:|---|---|---|
| 1 | Hilsner og høflighed | greet, thank, say goodbye | meeting/reception |
| 2 | Ja, nej, undskyld | basic responses, ask repetition | repair dialogue |
| 3 | Tal, priser og betaling | understand/use basic amounts | paying |
| 4 | På café | order a simple drink/snack | café |
| 5 | Restaurant og mad | simple ordering/questions | restaurant |
| 6 | Butik og indkøb | ask for item/price | shop |
| 7 | Hotel og overnatning | check in/basic requests | hotel |
| 8 | Tog, bus og billetter | buy/find transport | ticket |
| 9 | Vejvisning og steder | ask/find a place | directions |
| 10 | Hjælp og problemer | explain very simple problem | help/recovery |

## Lesson production template

Each released lesson should include:
- clear practical objective;
- small vocabulary set;
- approximately 10 high-value bilingual communication items;
- Polish TTS;
- Danish TTS where useful;
- minimal grammar note;
- short cultural/pragmatic note when relevant;
- 3-question quiz;
- links to one or more Samtaletræning scenarios where relevant.

## Beginner constraint

Do not require the learner to understand a case table before using a phrase. Level 1 can mention patterns, but systematic case learning starts in Level 2.

## Content uncertainty markers

Use:
- **LINGUISTIC REVIEW** for Polish correctness/progression uncertainty.
- **OPEN** for product decisions.
- **NICE-TO-HAVE** for deferred enrichment.
